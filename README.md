# apptech-studio.github.io

Trang chủ giới thiệu sản phẩm của **AppTech Studio** (GitHub Pages — user site).

- URL: https://apptech-studio.github.io/
- Giới thiệu các app iOS: **EduGrade**, **Moto Doc Inspector** (Vehicle Management).

## Cấu trúc
```
index.html        — landing giới thiệu sản phẩm
assets/style.css  — style landing
```

Trang policy (privacy/terms/support) nằm ở repo riêng **apptech-legal**, publish tại
https://apptech-studio.github.io/apptech-legal/ và được link từ landing này.

## Deploy
Push lên nhánh `main` → GitHub → repo Settings → Pages → Source: `main` / `/ (root)`.
